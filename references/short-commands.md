# Short commands

Type these phrases or say them in an interface that converts speech to text. Full sentences and a skill name are optional.

| Function | English | 简体中文 | 日本語 | Français | Español | Português |
| --- | --- | --- | --- | --- | --- | --- |
| Daily Tarot | Daily card | 今日牌 | 今日のカード | Carte du jour | Carta del día | Carta do dia |
| Daily I Ching | Daily hexagram | 今日卦 | 今日の卦 | Hexagramme du jour | Hexagrama del día | Hexagrama do dia |
| Reading about a question | Tarot + question | 塔罗＋问题 | タロット＋相談 | Tarot + question | Tarot + pregunta | Tarô + pergunta |
| Birth chart | Birth chart | 看星盘 | 出生図 | Thème natal | Carta natal | Mapa astral |
| Relationship line | One line | 来一句 | 一言ちょうだい | Une phrase | Una frase | Uma frase |
| Support | Just listen | 听我说 | 話を聞いて | Écoute-moi | Escúchame | Me escuta |
| Instructions | How to start | 怎么玩 | 使い方 | Comment commencer | Cómo empezar | Como começar |

- Daily commands use the supplied card or cast when available. Reuse a result for the same method from today in the current conversation. Otherwise draw one Tarot card or cast one hexagram. A focus can follow the command, for example “今日牌 工作”.
- A Tarot question without a named spread defaults to one card. “塔罗” by itself can use the question already being discussed. Ask for the question if there is none.
- For a birth chart, use the chart or placements already shared. For a new calculation, ask only for necessary details still missing.
- For “one line”, use the topic already under discussion. Without a topic, offer one original line about relationships or growth. A request for a specific person's quote goes to source lookup instead.
- For “just listen”, acknowledge what the person has shared or invite them to start. For instructions, use the language-matched participant guide.

Voice commands rely on the interface to supply a transcript. When a speech transcription mixes up a name or changes the meaning of a request, resolve the ambiguity with one concise question if needed.
